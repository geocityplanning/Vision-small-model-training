# 小目标检测训练脚手架

从整帧图像里学习小目标的位置与尺寸，输出中心点热力图和宽高。给的是训练、导出、评估这一套流程，与具体业务数据无关。

## 目录

```
train/train_det.py     训练：整帧进，中心点出
requirements.txt       依赖
```

## 数据格式

每行一条，jsonl：

```json
{"image": "001.jpg", "size": [1280, 720], "boxes": [[x, y, w, h, "类别"], ...]}
```

坐标以像素为单位，左上角原点。`frame` 字段可选，用来直接指定图片的绝对路径。

## 训练

```bash
python3 train/train_det.py --boxes data/boxes.jsonl --frames data/images \
    --epochs 60 --bs 4 --width 1280 --height 384 --base 32 --out runs/det/v1
```

参数说明：

`--width` `--height` 输入画布，按数据的实际长宽比设，不要硬套默认值。

`--crop-top` 只取画面上部若干比例，目标集中在画面上半部分时用它省算力。

`--base` 通道基数，默认 32；数据量小、目标形状单一时降到 16 能快一倍。

`--scale-jitter` 随机缩放幅度，默认关闭；同一类目标在不同分辨率下尺寸差别大时打开，取值 0.3 到 0.5。

## 产物

`runs/det/v1/best.pt`，按验证集损失挑的最优轮次。文件里存了模型权重和画布尺寸、裁切比例、通道基数这几个训练参数，推理时要按同一组参数还原。

## 注意

训练集与验证集按帧随机切分会让相邻帧同时出现在两边，指标会虚高。视频或连拍数据要按片段切分后再评估。

同一目标被遮挡、只露出局部时，标注框只框露出的部分，不要让框包含被遮住的位置，否则训练出的尺寸分布会互相矛盾。
